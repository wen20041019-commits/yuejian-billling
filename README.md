# 月见账

一款简洁、日系白色调的本地 Android 记账 App：快速记账、月度总结、预算超额预警，并可从微信支付和支付宝的付款通知自动记录支出。

## 功能

- 手动记录金额、分类、备注和日期
- 读取后续出现的微信支付、支付宝付款通知并自动记账
- 查看本月明细，长按可删除误记项目
- 按分类汇总本月支出
- 自定义月预算，在达到 80% 和超额时显示预警
- 根据剩余预算和本月剩余天数给出每日可用金额
- 所有账目仅保存在手机本地，不上传账号或支付密码

## 运行

```bash
npm install
npm run android
```

Android 原生项目位于 `android/`。自动记账需要用户在系统设置中授予“通知使用权”；受 Android 和支付应用通知内容限制，它只能识别授权之后收到且包含金额的付款通知，不能导入历史账单。

## 构建 APK

```bash
cd android
./gradlew assembleRelease
```

构建完成后，APK 位于 `android/app/build/outputs/apk/release/`。
